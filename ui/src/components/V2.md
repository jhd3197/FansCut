# v2 pieces: what to use where

Source: the "v2 · Components" board. CSS lives in `src/styles.css` (tokens at the top,
"v2 kit" section at the end). React helpers live in `src/components/v2.jsx`.
Never hard-code hex in a page: use the variables below.

## Tokens (CSS variables)

| Variable | Value | Use |
|---|---|---|
| `--sky` | #00AEEF | Actions and whatever is selected. Text on Sky: `--on-sky` |
| `--sky-hover` / `--sky-text` / `--sky-soft` | | Hover fill / link hover / dashed AI tag text |
| `--page` | #0A1A21 | Page background (also `--bg`) |
| `--panel` | #0F232C | Cards and panels |
| `--raised` | #142D38 | Buttons, selected rows (also `--panel2`, `--poster`) |
| `--hover` | #1B3A47 | Hover on Raised things |
| `--border` / `--border-hover` | #234453 / #44697A | Outlines, dividers (also `--line`, `--line-hover`) |
| `--deep` / `--deep-line` | #07141A / #132A34 | Sidebar and header bars |
| `--well` | #0D2028 | Inside of text fields and lanes |
| `--porcelain` | #F5FAFC | Main text (also `--text`) |
| `--soft` | #DBE7EC | Read-only tags, chip text (also `--text2`) |
| `--dim` | #A9BDC7 | Secondary text (also `--muted`) |
| `--faint` | #84A0AC | Labels and captions |
| `--apricot` | #FFBE98 | Already used, or not synced yet (also `--warn`) |
| `--coral` | #FF8F73 | Needs a look before you build |
| `--film-1`..`--film-8` | | One colour per film |
| `--ok` `--danger` `--info` | | Job/health states only; all 4.5:1+ on panel |

Fonts: `var(--display)` Outfit for titles (`h1`, `h2`, or class `.hd`), `var(--font)` DM Sans for
everything else, `var(--mono)` DM Mono for times and counts (class `.mono`). All bundled.
`h1` is 30px/700, `h2` is 20px/600.

## Buttons

- `.btn .btn-primary` - one per screen, the thing the screen is for.
- `.btn` - everything else. `.btn-sm` inside rows and cards.
- `.btn .btn-sm .btn-quiet` - the opposite of the button next to it (Drop next to Keep).
- `.btn-ghost` (older) still works for close/dismiss crosses.
- `<IconButton kind="play|pause|next|prev" label go/>` (`.icon-btn`, `.icon-btn.is-play`) - player controls only.
- Disabled-not-yet: `<button className="btn" disabled title="Not yet">`.

## Navigation

- Sidebar: `App.jsx` `Nav` (`.side`, `.nav a`, `.nav a.active` filled Sky, `.count` mono). Order:
  Discover, Library, Sets, My cuts, Jobs, Health, Settings; Logs and API docs in `.side-foot`.
- `<EditorSteps cut={id} step="find|arrange"/>` (`.esteps`, `.estep`) - the two steps of making a cut,
  only in the editor. Links to `/cuts/:id/find` and `/cuts/:id/arrange` (those routes are added by
  the Find and Arrange pages).
- Crumbs: existing `<Crumbs items/>` from `kit.jsx`.

## Tags: four looks, four meanings

1. `<FilterChip on count>` (`.fchip`, `aria-pressed`) - narrows what you see, changes nothing.
   Also "one of a few" choices (`.fchip .fchip-sm` with `role=radio aria-checked`).
2. `<EditTag name onRemove/>` (`.tag-edit`) + `<button className="tag-add">Add tag</button>` -
   solid Sky with a cross. Only in Scenes and tags.
3. `<AiTag name onKeep onDrop/>` (`.tag-ai`) - dashed until a person keeps it.
4. `<ReadTags tags/>` (`.tags-read`) - plain text "A · B · C". Find scenes, cut page, anywhere tags
   are just information. Names only, never the `fc:` prefix.

`.tags-row` lays any of these out in a wrapping row.

## Film colours

- `FILM_COLOURS`, `filmColour(i)`, `filmColours(keys)` -> `{key: colour}` in first-use order.
  (`SRC_COLOURS` in kit.jsx is the same list.)
- Set `style={{'--film': colour}}` and use `.film-dot` (8px dot), `.film-stripe` (4x30 bar in a
  film group head), `.film-tint` / `.film-poster` (stand-in poster for a film with no art).
- `<FilmDot colour/>`.

## Controls

- `<Switch on onChange label/>` (`.toggle`, role=switch) - a setting that is on or off.
- `<Tick on onChange label/>` (`.tick`) - in the cut or not, on scene cards.
- `.nudge` - `-1s` / `+1s` trim buttons, only in Arrange.
- `.inp` - text field (asking AI, searching, naming). `.input` (older) still works.
- `.lab` / `<Label>` - small caps label above a group. Never a button.

## Status

- `<JoinStatus state="check|clean|unchecked">text</JoinStatus>` (`.join .join-*`). Check = Coral
  triangle ("Line ends 0.2s before the cut"); clean = light dot; unchecked = dashed ring
  ("Film not analysed").
- `<ReadyState ready>` (`.state .state-ready` Sky dot / `.state-missing` Apricot ring) - Discover cards.
- `.state-used` (Apricot dot, already used / not synced), `.state-look` (Coral dot, needs a look).
- `<PreviewBadge/>` (`.preview-badge`) - on every player that is not the built file.

## Panels and layout

- `.box` - a panel section (Panel fill, 12px radius). `h2` as first child gets its spacing.
- `.well` - a darker inset list container (Page fill) for rows.
- `.card` (older) still works; prefer `.box` for new v2 panels.
- Tables: existing `.table` (plain tables with counts).

## Player and rows

- `<GluedBar parts={[{len, colour, played}]}/>` (`.glued`) - one segment per scene, coloured by
  film, bright = played.
- `.build-band` - always directly under a preview player: text block, mono estimate, primary Build.
- Scene card (Find scenes): `.scene-card` (+ `.is-out` left out, `.is-unsure` AI not sure) >
  `.scene-frame` (img, `<Tick>`, `.scene-len`) + `.scene-film` (FilmDot + name) + `.scene-time` + `.scene-tags`.
- Film group (cut page, read-only): `.film-group` > `.film-group-head` (`.film-stripe`, name block,
  mono length) + `.film-group-row` (thumb, mono range, length). Clicking a row only moves the preview.
- Running order row (Arrange): `.order-row` (`.grip`, `.n`, thumb, name, mono length), selected
  `.is-on`; join under it: `.order-join` holding a `<JoinStatus>`.
